# TaskFlow

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)

TaskFlow — учебный REST API менеджера задач. Проект предусматривает пользователей, проекты, задачи и комментарии; схема данных разработана в предыдущей лабораторной работе.

## Статус

Комплект содержит документацию и самостоятельный пример Python. По ЛР № 5 добавлен пустой каркас backend/app.py и другие файлы backend/, но работающий HTTP-сервер пока не реализован. Инструкции запуска относятся к будущей реализации и требуют проверки на её исходном коде.

## Установка и запуск сервера

1. Получите исходный код реализации TaskFlow и откройте его папку в терминале. Убедитесь, что в ней есть app.py. Ссылка на репозиторий пока не опубликована.
2. Создайте виртуальное окружение:

```bash
python -m venv .venv
```

3. Активируйте окружение в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Для Linux/macOS: `source .venv/bin/activate`.

4. Установите базовые библиотеки:

```bash
python -m pip install Flask SQLAlchemy
```

Если реализация содержит requirements.txt, используйте `python -m pip install -r requirements.txt`: этот файл должен фиксировать все зависимости, включая библиотеку авторизации.

5. Выполните предусмотренную реализацией настройку SQLite и секретов авторизации. Команда инициализации БД зависит от кода и здесь не предполагается.
6. Запустите сервер разработки:

```bash
python app.py
```

Ожидаемый адрес локальной реализации: http://127.0.0.1:5000. Его необходимо сверить с настройками приложения. Сервер разработки не предназначен для публичного размещения.
