# Changelog

История оформлена по [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Это учебный сценарий релизов по заданию: даты условные, записи не подтверждают фактическое развёртывание сервера.

## [1.0.0] - 2026-10-11

### Added

- Регистрация и вход пользователей с токеном доступа.
- Docker-конфигурация для упаковки приложения.
- Инструкция и конфигурация деплоя приложения.

### Changed

- Доступ к операциям с задачами ограничен авторизованными пользователями.

## [0.2.0] - 2026-10-04

### Added

- CRUD задач: создание, список, просмотр, обновление и удаление.
- Поля статуса, приоритета, проекта и исполнителя задачи.

## [0.1.0] - 2026-09-27

### Added

- Начальная структура проекта TaskFlow на Python и Flask.
- Схема SQLite для users, projects, tasks и comments.
- Базовая документация проекта.
